A page an agent is driving

The border around this viewport is the persistent agent marker. It breathes on a 2.6s cycle — slow enough to read as ambient rather than as an alert, and never dim enough to be missed. Set “reduce motion” in your OS and it should hold steady at full strength instead.

The card at the top is what appears in every window when a session has to be told which one to work in. Only the card takes clicks; the page behind it stays usable.

Click Move cursor to send the live pointer somewhere on the page: it glides to the point, squeezes, and rings on contact — the same feedback a real trusted click produces during a run. It is the one marker that persists between actions, so you can always see where the agent last was.
