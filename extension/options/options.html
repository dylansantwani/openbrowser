Open-source browser automation for AI agents. Everything the extension can do is also available over MCP — and nothing here leaves your machine except the pages you ask it to visit.

1 · Start the MCP server Point your MCP client at it, or run it yourself from the project directory:
node mcp-server/src/index.js
2 · Open the side panel Click the toolbar icon (or press Ctrl+Shift+U) and hit Snapshot page to check it works.
