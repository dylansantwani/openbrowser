OpenBrowser

Open-source browser automation for AI agents. Everything the extension can do is also available over MCP.

Getting started

  1. Start the MCP server. Point your MCP client at it, or run it yourself from the project directory: node mcp-server/src/index.js
  2. Check the connection. The badge on the toolbar icon clears when the extension is connected. Current status: checking…
  3. Try it. Open the side panel (toolbar icon, or Ctrl+Shift+U) and hit Snapshot page.
